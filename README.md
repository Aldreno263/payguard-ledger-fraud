# PayGuard — Payment Transaction Processing & Fraud Analytics

Simulasi backend pemrosesan transaksi keuangan (Ledger API) dan pengolahan data transaksi untuk analisis serta deteksi anomali (Fraud Analytics).

## 📌 Fitur Utilitas (MVP)
- **Account Management**: Pembuatan dan pengelolaan akun simulasi.
- **Balance & Transaction Inquiry**: Pemeriksaan saldo virtual dan pencatatan transaksi atomik.
- **Ledger Entries**: Pencatatan berpasangan debit/kredit untuk integritas transaksi.
- **CSV Data Export**: Ekspor dataset transaksi untuk analisis sistem FinData/Analytics.

## 🛠️ Stack Teknologi
- **Language**: Python 3.x
- **Framework**: FastAPI (dalam pengembangan)
- **Database**: MySQL / SQLAlchemy ORM
- **Tools**: Git, VS Code
